# AutoCAD 2027 플러그인 (GaRuleCheck.dll)

엔진(Python)이 판정하고, 이 플러그인은 **도면 스냅샷 추출 → 엔진 호출 → 결과 표시**만 하는 어댑터다.

> v0.1(2026-10-12) AutoCAD 2027에서 빌드·실행 확인. v0.3 소스는 10-12 16:04 빌드됨(리포트 생성 확인).
> **v0.3.2(10-12 3·4차 수정: layer_counts 전송, 'GA' 접두 레이어 감시 신호, 엔진 주소 허용 목록·리다이렉트 금지 / 10-13 '발표 모드' → '라벨 확대'·명령 `GARCLARGE`)는 빌드 미확인** — `install.ps1`로 다시 빌드할 것.
> v0.3.1(10-12 오류 수정: Extractor·EngineClient·ShipInfoView·DocWatcher·Dto)은 10-12 18:34 사용자 PC에서 빌드 성공(`Polyline2d.VertexPosition`, `Vertex2dType.SplineControlVertex`, `Vertex3dType.ControlVertex`, `HttpClientHandler.UseProxy` 모두 컴파일됨). **실기 동작은 아래 확인표 1~14로 확인할 것** — 오류가 나면 메시지·스크린샷 그대로 Claude에게.

## 준비물
- AutoCAD 2027 (.NET 10) — LT 버전은 .NET 플러그인 불가
- .NET 10 SDK (`dotnet --list-sdks` → 10.x). 설치: `winget install Microsoft.DotNet.SDK.10`
- (Visual Studio를 쓸 경우 2026 이상 — VS 2022는 .NET 10 대상 빌드 불가)
- AutoCAD 2025/2026(.NET 8)에서 쓰려면 `-p:TargetFramework=net8.0-windows -p:AcadDir=...`로 따로 빌드 (버전 간 바이너리 호환 없음)
- Python 3.10+ (엔진 서버)

## 빌드
```powershell
cd autocad\GaRuleCheck
dotnet build -c Release
# AutoCAD 경로가 기본값이 아니면:
dotnet build -c Release -p:AcadDir="D:\Program Files\Autodesk\AutoCAD 2027"
```
결과: `bin\Release\net10.0-windows\GaRuleCheck.dll`

## 자동 로드 설치 (권장 — NETLOAD·서버 실행 생략)
AutoCAD를 **모두 닫고** PowerShell에서:
```powershell
cd autocad
powershell -ExecutionPolicy Bypass -File .\install.ps1
```
1. 빌드 → 2. `%APPDATA%\Autodesk\ApplicationPlugins\GaRuleCheck.bundle`에 설치(AutoCAD 2027 시작 시 자동 로드) → 3. `GARC_ENGINE_DIR`·`GARC_PYTHON` 사용자 환경변수 설정(`GARC` 입력 시 엔진이 꺼져 있으면 최소화 창으로 자동 실행).
- 코드를 고친 뒤에도 같은 명령으로 다시 설치한다(AutoCAD는 번들 복사본을 쓰므로 `bin` DLL이 잠기지 않는다).
- 처음 한 번 보안 경고가 뜨면 "항상 로드". 매번 뜨면 옵션 → 파일 → 신뢰할 수 있는 위치에 번들 폴더를 추가.
- 제거: `.\uninstall.ps1`

## 수동 실행
1. 엔진 서버 켜기 (별도 터미널):
   ```powershell
   cd engine
   python -m garc serve        # http://127.0.0.1:8765
   ```
   환경변수 `GARC_ENGINE_DIR`에 engine 폴더 경로를 넣어 두면, 연결 실패 시 플러그인이 한 번 자동 실행을 시도한다.
2. AutoCAD에서 `NETLOAD` → `GaRuleCheck.dll`
3. 샘플 도면 열기: `samples\S140_rev0_base.dxf` (DXF를 열고 DWG로 저장해도 된다)
4. `GARC` → 오른쪽 팔레트에 결과가 뜬다.

## 화면 (v0.2)
- **리본 'GA RuleCheck' 탭** — 검토(검사 시작·지금 검사·감시 중지) / 입력(선박 정보·조종위치·초기 설정) / 표시·기록(표시 켜기/끄기·리포트)
- **팔레트** (AutoCAD 다크 테마)
  - 상단: 전체 판정 점·문구, `rev · 도면 · 시각`, 엔진 연결 상태, [다시 검사] [도면 표시] [리포트]
  - **검토 탭**: 규칙 카드 — 상태 띠·배지, 메시지, 현재값/허용값 게이지, 최악 조건, 제안, [대상 보기], [근거 ▾](미검토 범위). 상태가 바뀌면 맨 위에 "새 위반 / 해결" 배너
  - **선박 정보 탭**: LOA·L·AP·FP·기선·눈높이·용골 거치일·단위, 흘수 조건 표 편집 → [저장 후 검사]. AP·FP·기선은 [도면에서]로 점 지정, [조종위치 지정]으로 GA_EYE 점 생성/이동
  - **이력 탭**: revision 타임라인(추가/삭제/수정, Undo 표시, 판정 변화)
  - 하단: 면책 문구 고정
- **도면 위 표시** (Transient): 위반 객체 빨강/검토 불가 주황, 시선(초록/빨강), 최악 조건 수선(하늘), 허용 한계선·충돌격벽 허용 구간(노랑), 기준점, 라벨("사각 433.8 m", "허용 상단 z ≤ 22.45 m", "d=11.00 m" …). 라벨은 맑은 고딕 TrueType 스타일 `GARC_LABEL` 사용
- **리포트**: DWG 옆에 `<도면>_GA검토_<시각>.html` 저장 후 브라우저로 열림 — 요약, 측면도 SVG, 규칙별 판정식·중간값·미검토 범위, 입력 요약, 변경 이력. 인쇄(PDF 저장) 가능
- 다른 도면 탭으로 바꾸면 팔레트가 그 도면 결과로 바뀌고, 선박 정보가 입력된 도면은 자동 감시

### v0.3 추가
- **상태 표시줄 아이콘**(오른쪽 아래): 초록 ✓ / 빨강 ✕ / 주황 ! 로 현재 판정, 마우스를 올리면 요약. 새 위반·사람 확인이 생기면 **풍선 알림**. 아이콘 클릭 → 팔레트 열기 (팔레트를 닫아 둬도 상태가 보임)
- **객체 툴팁**: 위반·검토 불가 객체에 커서를 올리면 규칙·수치·제안이 AutoCAD 툴팁으로 표시
- **카드 호버 강조**: 팔레트 카드에 마우스를 올리면 해당 객체가 도면에서 자홍색으로 강조
- **[범위 보기]**: 시선·허용 한계선·대상 객체가 한 화면에 들어오게 자동 줌 (사각 거리가 수백 m라 수동 줌이 번거로운 문제 해결)
- **라벨 확대**(구 '발표 모드'): 도면 위 라벨 글자·선 두께·표식 크기만 2.5배 — 프로젝터·화면 공유에서 잘 보이게. 판정·도면 객체·시스템 변수는 바뀌지 않음 (리본·팔레트·`GARCLARGE`)
- 카드 배경이 검게 칠해질 수 있던 문제 수정(투명 부모 위 Clear)

## 설계 메모
- **표시는 Transient(임시 그래픽)만** 쓴다. 도면 DB를 수정하지 않으니 Undo 기록이 오염되지 않고 저장 파일에도 남지 않는다.
- **이벤트는 "다시 검사" 신호로만** 쓴다. 매번 GA_ 레이어 전체를 스냅샷으로 보내고, 무엇이 바뀌었는지는 엔진이 계산한다(→ Undo/Redo/복사/레이어 변경 어느 경로든 동기화가 맞음).
- 엔진 연결 실패·플러그인 예외 → 항상 "검토 불가"로 표시. 초록으로 남지 않는다.
- **판단 없는 추출**: 폴리선 호는 bulge 값만 보내고 분할은 엔진이 한다. 블록은 삽입점만 보내며, 엔진이 GA_EYE 외 레이어 블록을 멈춘다.
- **엔진 주소는 루프백만**: `GARC_ENGINE_URL`이 127.0.0.1·localhost·::1의 http 주소가 아니면 무시하고 기본값을 쓴다. HttpClient는 시스템 프록시를 쓰지 않는다(`UseProxy = false`).
- **문서 ID**: FingerprintGuid + 열린 문서마다 새 GUID. 같은 원본에서 복사한 도면을 동시에 열어도 엔진 세션이 섞이지 않는다(문서를 다시 열면 이력은 새로 시작).
