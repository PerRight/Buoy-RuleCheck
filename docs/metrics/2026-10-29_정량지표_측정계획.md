# 정량지표 측정 계획 (3주차, 2026-10-29)

심사 기준 '창출 효과 20점'은 수치 증명이고, 설득력 점검 항목에는 ROI와 Before/After가 있다. 측정 방법은 2강 기준을 따른다(프로젝트 문서 `claude/2강_적용노트_2026-10-20.md`).

- 판정일치율은 **개발에 쓰지 않은 봉인 입력**에서만 낸다.
- 검토 시간은 엔진 응답이 아니라 **설계자가 판단을 끝낸 시간**을 기존 방식과 비교한다.
- 증거 범위를 넘는 말은 하지 않는다.

## A. 봉인 확인용 입력 (판정일치율)

1. **작성자**: 엔진을 만들지 않은 사람(복준용·표인범)이 쓴다. Claude와 개발자는 실행 전까지 기대값을 보지 않는다.
2. **구성**: 6~8건을 만든다. 규칙마다 3~4건씩, 정상 1 · 경계 1 · 위반 1 · 누락이나 충돌 1이 되게 고루 넣는다. 24건과 같은 값을 쓰지 말고 새 치수로 만든다.
3. **기대값을 먼저 손으로 계산**해 아래 양식에 적는다(계산 과정 한 줄 포함).
4. **봉인**: 다 쓴 파일을 팀 채팅에 올려 시각을 남긴다. 그 뒤로는 고치지 않는다.
5. **실행**: 손종민(또는 Claude)이 입력을 엔진 형식으로 옮겨 **한 번만** 실행한다. 일치 수를 세서 그대로 기록한다.
6. **불일치**가 나오면 손계산 오류인지 엔진 오류인지 둘이 함께 확인해 기록한다. 엔진을 고쳤다면 그 입력은 확인용으로 다시 쓸 수 없으니, 새 확인용 입력을 만든다.

## B. 판단 완료 시간 (Before/After)

**질문**: GA를 바꾼 뒤 "규정 문제가 있나, 있으면 얼마나 고쳐야 하나"를 판단하기까지 기존 방식과 플러그인 중 어느 쪽이 얼마나 빠르고 정확한가.

**참가자** 2~3명(팀 밖 조선해양 전공자 1명이 있으면 가장 좋다). 팀원은 답을 알고 있을 수 있으니 결과에 표시한다.

**과제** 3개. 같은 사람이 같은 도면을 두 번 풀면 두 번째가 빨라지므로, 수치만 다른 a/b 두 벌을 쓴다. 과제 도면(S140 변형 DXF)은 날짜가 정해지면 Claude가 만든다. 답은 측정 담당만 갖는다.

| 과제 | 바뀐 것 | 판단할 것 |
|---|---|---|
| T1 | 갑판에 컨테이너 추가 | 가시거리 문제가 있나, 상단을 몇 m 이하로 해야 하나 |
| T2 | 충돌격벽 위치 이동 | 허용 범위 안인가(구상선수 기준점 포함), 얼마나 옮겨야 하나 |
| T3 | 흘수 조건 하나 추가(선수 트림) | 어느 조건이 가장 불리하고, 문제가 있나 |

**방법**
- 기존 방식: AutoCAD 측정(`DIST`, 선 긋기)과 계산기·엑셀을 쓴다. 조항 요약 1장을 준다(공정하게).
- 플러그인: Buoy-RuleCheck를 쓴다.
- 참가자 절반은 기존 방식부터, 절반은 플러그인부터 시작한다. a/b 벌도 바꿔 가며 쓴다.

**재는 법**
- 시작은 과제 도면을 연 순간이다.
- 끝은 "문제없음 / 수정 필요 + 수치"를 말하거나 적은 순간이다.
- 스톱워치로 초 단위로 잰다. 답이 맞았는지도 적는다. **틀린 '문제없음'은 따로 센다**(가장 위험한 실수).

## C. 실도면 첫 검사까지 (선택)

GA_ 레이어가 없는 실도면 복사본 1건으로 잰다. 쓸 수 있는 실도면(권리 확인)이 있을 때만 한다.
- 기존: 레이어를 손으로 다시 나눠 `GA_` 레이어로 옮기는 데 걸린 시간
- 플러그인: `BRCLINK` 마법사 5단계로 첫 판정까지 걸린 시간

## D. ROI (B 이후)

```
연간 절감액 = 건당 절감 시간(B 측정) × 월 GA 변경 건수 × 시간당 인건비 × 12
ROI = 연간 절감액 ÷ 도입·운영 비용
```

| 항목 | 값 | 근거 |
|---|---|---|
| 건당 절감 시간 | (B 결과) | **측정** |
| 월 GA 변경 건수 | | **가정** — 멘토·현직자에게 확인 |
| 시간당 인건비 | | **가정** — 출처 적기 |
| 도입·운영 비용 | | **가정** |

발표에서는 측정값과 가정값을 색이나 표시로 나눠 보인다. 재작업 비용(검도·선급 코멘트 단계에서 위반을 늦게 알아 다시 그리는 시간)은 숫자 근거가 없으면 정성적으로만 말한다.
