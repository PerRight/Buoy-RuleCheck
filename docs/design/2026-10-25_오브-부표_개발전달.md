## 한 줄 요약

지금은 위반 객체를 빨강으로 칠하고 시선·허용선·라벨을 항상 그립니다.
앞으로는 **평소에는 고칠 위치에 '부표(오브)'만** 띄우고, **마우스를 올리면** 근거 선과 카드를 보여줍니다.
고쳐서 문제없음이 되면 부표가 파랑으로 바뀌며 멈추고, 한 번 올려 확인하면 사라집니다.

```
수정 소요 발생 → 부표 등장(자전 시작, 물결 2번) → 호버: 카드(고칠 내용) + 근거 선
→ 설계자가 수정(명령 중 멈춤 + 흐림) → 다시 검사(빠르게 자전)
→ 문제없음(파랑으로 바뀌며 멈춤, 확인 대기) → 호버: '문제없음' 카드 → 떠나면 사라짐
```

**오브가 3D로 보이는 이유 4가지** (전부 지켜야 입체감이 납니다)
1. 구 위에 점을 고르게 깔고(해바라기씨 배치), **매 프레임 구를 돌려서** 점 위치를 다시 계산합니다.
2. 앞으로 오는 점은 **크고 진하게**, 뒤로 넘어가는 점은 **작고 흐리게**.
3. 빛은 **왼쪽 위**에서 옵니다. 점은 오른쪽으로 갈수록 조금 어두워집니다. 로고는 **점만** 있고 뒤에 구 몸통이 없습니다.
4. 속도를 바꿀 때 **회전각을 절대 0으로 되돌리지 않습니다**. 각속도만 부드럽게 바꿉니다(끊김 없음).

## 5. 상태 머신 — 문서별 `BuoyStore`

키는 `(rule_id, element handle)`입니다. 블록이면 base handle을 씁니다. 부표마다 **회전각 A와 현재 속도 v**를 들고 있습니다.

| 이전 → 새 결과 | 부표 | 속도 목표 |
|---|---|---|
| 없음 → fail | 새 부표, 등장 + 물결 2번 | 1 (5 s/바퀴) |
| fail → fail | 유지, 카드 수치만 갱신 | 1 |
| fail → pass | 파랑 '문제없음'(확인 대기)으로 바뀌며 멈춤 | 0 |
| fail → na / review / unknown | 주황 '확인 필요', 빈 조각을 보이며 자전 | 5/8 (8 s/바퀴) |
| fail → 객체 삭제 (규칙 판정 가능) | 파랑 '문제없음'. `/v1/compare`의 '해결' 기준과 같게 | 0 |
| 문제없음 → fail (Undo 등) | 같은 키로 빨강 재등장 | 1 |

**명령과 검사 중**
- 명령 실행 중에는 해당 부표를 35%로 흐리고 속도 0(0.24 s에 정지). 지금은 `CommandEnded`만 걸려 있으니 `CommandWillStart`를 추가하세요.
- 엔진 호출 중에는 '검사 중': 속도 ×4.17(1.2 s/바퀴)로 0.42 s 동안 가속. 최소 0.6 s 보여줍니다.
- 결과가 오면 0.64 s 동안 감속해 멈추고, 색은 0.3 s에 걸쳐 파랑으로.

**속도 바꾸는 법 (끊김 없이)**
```
매 프레임:  v ← 목표로 가는 램프 값,  A ← A + (2π / 5 s) · v · dt
θ_k = λ_k + A        # A는 절대 0으로 되돌리지 않는다
```

**문제없음 부표가 사라지는 시점**
- 호버해서 카드를 본 뒤 떠나면 사라집니다.
- 또는 저장(`SaveComplete`) 때 한꺼번에 정리하고, 버전 기록에 '해결 n건'으로 남깁니다.

## 8. 오브 점 좌표 — 자전하는 구 (시안과 같은 식)

```
크기 s(px) 등급        점 N   점 계수 k
  XS  s ≤ 20          24     0.13
  S   s ≤ 40          36     0.105     ← 부표(30), 떠 있는 로고(36)
  M   s ≤ 96          80     0.066
  L   그 위           160    0.037     ← 브랜드 큰 로고
R = 0.4·s,  c = s/2,  D = s·k,  기울기 t = 18° (북극이 보는 쪽으로 기울어 윗면이 보임)

점 배치 (해바라기씨, 한 번만 계산):
for i in 0..N-1:
    y_i = 1 − 2(i + 0.5)/N
    φ_i = asin(y_i)
    λ_i = (i · 137.5078°) mod 360          # 황금각
    부표 등이 있으면 y_i > 0.93 인 점은 뺀다
    확인 필요면 λ_i ∈ [280°, 359°] 인 점을 뺀다 (빈 조각)

매 프레임:  θ_i = λ_i + A
X = c + R·cosφ·sinθ
Y = c − R·sinφ·cos t + R·cosφ·cosθ·sin t
f = (sinφ·sin t + cosφ·cosθ·cos t + 1) / 2          # 깊이, 1 = 가장 앞
지름 = D · (s_min + (1 − s_min)·f)
알파 = (o_min + (1 − o_min)·f^1.2) × 빛 × 위아래 × 수선
   빛    = 1 − (1 − l)·(sinθ + 1)/2                    # 왼쪽 밝음 → 오른쪽 어두움
   위아래 = 로고 0.95 + 0.05·y  /  부표 1
   수선   = y < −0.3 이면 (로고 0.76 / 부표 0.85), 아니면 1
f 오름차순(뒤 → 앞)으로 그린다

             s_min   o_min   l
로고          0.30    0.08    0.76
부표          0.45    0.28    0.86      # 바쁜 도면에서 묻히지 않게 더 진하게

몸통(부표만, 로고는 없음):  중심 (c, c), 반지름 R + 0.35·D
       방사형 그라데이션 중심 (0.36·s, 0.30·s)
       알파 0.12 → (42% 지점) 0.054 → (가장자리) 0.03, 색 = 점 색

       뒤쪽 절반은 구 뒤에(어둡게), 앞쪽 절반은 점 위에 그린다
```
