# 2026-10-13 기능·플러그인 디테일 구상 — 두 모델 비교 기록

> 질문: "본선(11-09) 시연·심사 관점에서 기능적·플러그인적으로 어떤 디테일을 더 추가할 가치가 있나?"
> 방법: fable 옵션 fork(이 날 런타임 검증 컨텍스트 보유) + opus 옵션 독립 에이전트(저장소 정독) 병렬 구상 후 종합.
> fable을 쓴 이유: 사용자가 두 모델 병행 구상을 직접 지시.

## 두 모델이 일치한 것 (신뢰도 최상 — 그대로 채택)

1. **플러그인 v0.3.2 빌드 + 첫 실행 확인표 1~14가 모든 것의 전제.** 시연 코드가 한 번도 실행된 적 없다는 것이 유일한 존재론적 리스크 (둘 다 1순위).
2. **엔진 서버 미기동이 가장 개연성 높은 데모 사고.** opus가 코드 근거 발견: `EngineClient`의 HTTP가 전부 UI 스레드 동기 호출이고, `EnsureRunning()`은 엔진이 꺼져 있으면 `Thread.Sleep(200)×25 = 최대 5초` AutoCAD 프리즈(`EngineClient.cs:106`). `TryStartEngine()`은 `GARC_ENGINE_DIR` 비면 침묵 반환, `python`이 PATH에 없으면(py 런처만 있는 PC) 조용히 실패.
3. **정량지표 훅을 미리 넣을 것** — `elapsed_ms`·캐시 여부를 응답에(2주차 초, 1~2h), 3주차 지표 하니스는 스크립트 수준 비용.
4. **데모 대본 고정** — rev0~4 상태별 DWG 사전 저장(라이브 드로잉 좌표 실수 폴백), [범위 보기] 단계 필수화(오버레이가 선수 앞 수백 m까지 나가 수동 줌으로는 안 보임), 500+ 객체 샘플 1개로 성능 리허설.
5. **24건 수기 검산** — `verified_by` 24건 전부 null인 상태로는 "24건으로 증명"의 설득력이 비어 있음 (기존 미결이지만 둘 다 재강조).
6. **하지 말 것 일치**: 자동 수정 버튼(DB 수정+승인처럼 보임), C# 판정 로직, 증분 추출, AI 설명이 도면 데이터를 외부로(오프라인 템플릿 기본 + 외부 LLM은 옵트인·판정 문구만), "모든 오타 잡는다" 발화, 급한 3번째 규칙(케이스 없이 규칙 금지).

## 갈린 것: 블록(INSERT) 전개

- **fable**: 최대 기능 구멍. 실제형 GA 샘플(2주차, 표인범)은 컨테이너·크레인을 블록으로 그릴 가능성이 높고, 그 순간 데모가 빨강(위반)이 아니라 주황(검토 불가)으로 끝남. Extractor(C#)+DXF 어댑터 양쪽 전개 권장 (각 4~6h). 전개는 '추출'이므로 판정은-엔진만 원칙 위반 아님.
- **opus**: C# 전개는 4주 안에 위험하고 원칙 경계가 흐려짐. 지금의 '블록이면 멈춤'은 오히려 "모르면 멈춘다"를 보여주는 좋은 장면(확인표 9). 유지하라.

**종합 결정(권고)**: 단계적 절충.
1. **DXF 어댑터(Python, ezdxf `virtual_entities`) 전개부터** — 엔진 쪽이라 24건 방식 그대로 테스트 가능, 저위험 (4~6h, 2주차).
2. **C# Extractor 전개는 조건부 2단계** — v0.3.2 실기 통과 후 + 실제형 샘플이 실제로 블록을 쓸 때만. 그 전까지는 표인범에게 "장애물은 폴리라인으로 그려 달라"고 샘플 제작 가이드로 회피 가능.
3. 전개 불가 블록(외부참조 등)은 지금처럼 `review` 폴백 유지.
※ CLAUDE.md §8 미결 "블록 장애물 지원(손종민)" 항목을 이 단계 구분으로 구체화할 것.

## 한쪽만 낸 것 중 채택 가치 높은 것

- (fable) **위반 카드 클릭 → 해당 객체 줌**(handle 기반, 뷰만 변경, 2~3h) + **캐시·응답시간 배지**("캐시 적중 · 8 ms", 2h) — Undo 캐시가 내부 사실에 머물지 않고 심사위원 눈에 보이게 됨.
- (fable) 팔레트 신뢰 배지("엔진 0.2.1 · 규칙 2 · 테스트 70 · 24건 수기 검증", 1h) — 멘토의 '판정을 어떻게 믿나'에 대한 화면 답변.
- (fable) 격벽 허용 밴드 Transient 표시(2~3h), 리포트 SVG 라벨 겹침 수정(1~2h).
- (opus) 설치 폴더를 본선 PC 신뢰 위치에 사전 등록(보안 경고 차단), `Overlay.Items`가 static이라 멀티 도면 상태 공유(단일 도면 데모면 무해 — 즉흥 멀티 도면 조작만 피하기).
- (opus) 엔진 비동기 선제 기동 + 팔레트 "엔진 켜는 중" 표시(중간 비용, 2주차) — 또는 최소한 리허설 대본에 "보이는 터미널에 serve 먼저" 고정.
